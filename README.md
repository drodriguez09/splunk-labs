# Splunk labs

Hands-on practice with Splunk as I prepare for the **Splunk Core Certified User** exam, while building out my SOC analysist skills. Everything here was built in my home lab!

**Status:** In progress

## What's in this repo

- `01-setup/` - How to install Splunk and load it with training data
- `02-search-practice/` - SPL searches which includes: what I predicted, what actually happened, and what I learned
- `03-investigation/` - *Coming soon:* a security investigation write-up

## Skills I'm practicing:

- Writing SPL (Search Processing Language) searches to analyze log data
- Using fields like `host`, `sources`, `sourcetype`, and `status` to narrow down search results
- Using **Transforming** commands: `stats`, `top`, `rare`
- Building reports, dashboards, and alerts
